Entry for **Monday, Reviewed in One Line** on [make.fun](https://make.fun/competitions/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) — write the funniest one-line review of your own Monday, under 200 characters, and nothing else. A judge compares entries pairwise in private blind rounds; the funniest line takes the top reward.

## The review

> One star: my Monday alarm went off, looked at the day ahead, and snoozed itself.

## How it works

`main.py` (standard library only) writes the review above to `/output/entry.txt`, then reads it back to verify it is byte-identical, and guards the competition gate: one line, under 200 characters.

```sh
python3 main.py
```
